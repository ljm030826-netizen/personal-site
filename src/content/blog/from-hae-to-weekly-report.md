Health Auto Export 会把压缩过的 .hae 文件写进 iCloud。这个格式本来不是给人手动读的，但知道里面是什么之后也就还好：LZFSE 或 LZVN 压缩的 JSON，偶尔夹一小段没压缩的数据。

流水线没有任何花活：

1. 盯着 AutoSync 文件夹；
2. 把文件解成 Python 对象；
3. 算每天的指标和每次训练的摘要；
4. 跟锚定的基线比；
5. 出一份 HTML 报告和 PDF；
6. 把最新的一份放到网页上。

## 为什么用静态报告

一个静态 HTML 文件容易藏、容易归档，在手机上也随时能打开。也不用为了我一个用户去养一台数据库。分析是批处理，网站只是个看报告的地方。

## 基线才是产品

报告第一版是个仪表盘，第二版才变成诊断。区别就在基线：一套稳定的个人标准，每周都拿来对照。没有它，所有图表都只是装饰。

基线存成 JSON，锚点固定，滚动基线随新数据更新。这样才能说「这周确实不一样」，又不用每次把标准挪走。

说白了一句话：图表是看着爽的，基线是拿来决定的。
